# EcoSentry 🌱

Aplikacija za digitalni nadzor i prijavu divljih odlagališta otpada.

## O projektu

EcoSentry povezuje građane, ekološke udruge i komunalne službe radi lakše prijave, praćenja i sanacije divljih odlagališta te organizacije akcija čišćenja.

Projekt se izrađuje u sklopu kolegija [Programsko inženjerstvo](https://www.fer.unizg.hr/predmet/proinz) na Fakultetu elektrotehnike i računarstva Sveučilišta u Zagrebu (FER).
